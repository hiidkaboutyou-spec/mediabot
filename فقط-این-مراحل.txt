1) همه فایل‌های همین پوشه را مستقیم داخل صفحه اصلی یک Repository خصوصی GitHub آپلود کن.
2) در Koyeb با GitHub وارد شو و Create Web Service را بزن.
3) Repository را انتخاب کن و Builder را Dockerfile بگذار.
4) Environment Variable بساز: BOT_TOKEN = توکن BotFather
5) پورت HTTP را 8000 بگذار و Deploy را بزن.
6) وقتی Healthy شد، در تلگرام /start و سپس /id را بفرست.
7) در Koyeb متغیر ALLOWED_USER_IDS را برابر آیدی عددی خودت بگذار و Redeploy کن.

هیچ فایل مخفی، Terminal، Homebrew یا کدنویسی روی Mac لازم نیست.
