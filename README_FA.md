# بات دانلودر رسانه برای تلگرام

«دانلودچی» یک بات پایتونی فارسی برای دریافت و ارسال رسانه از هزاران سایت با `yt-dlp` و پشتیبانی از لینک‌های Spotify با `spotDL` است. این پروژه با Docker اجرا می‌شود و فایل‌های استقرار Render و Railway هم دارد.

## قابلیت‌ها

- بررسی لینک رسانه و نمایش کیفیت‌های موجود، بهترین کیفیت یا صدای MP3
- دانلود پلی‌لیست‌های yt-dlp به‌ترتیب و ارسال جداگانهٔ فایل‌ها تا سقف تنظیم‌شده
- ارسال کپشن و اطلاعات رسانه
- Spotify track، album و playlist: دریافت اطلاعات قطعه‌ها و تطبیق نسخهٔ صوتی از منبع ثالث؛ فایل اصلی DRM اسپاتیفای دریافت نمی‌شود
- محدودیت حجم فایل، مدت رسانه، تعداد قطعه‌های Spotify و دانلودهای هم‌زمان
- محافظت از دسترسی با `ALLOWED_USER_IDS` و جلوگیری از لینک‌های میزبان محلی/خصوصی
- Health check روی `PORT` برای سرویس‌های میزبانی

yt-dlp فهرست بزرگی از سایت‌ها را پوشش می‌دهد، اما هیچ extractorی همیشگی یا تضمین‌شده نیست. برخی رسانه‌ها به ورود، کوکی، منطقهٔ خاص یا دسترسی ویژه نیاز دارند و ممکن است پشتیبانی سایت با تغییرات آن از کار بیفتد. فقط محتوایی را دریافت کنید که مجاز به دریافتش هستید.

## راه‌اندازی سریع با Docker

1. از BotFather یک بات بسازید و توکن را بردارید.
2. فایل `.env.example` را به `.env` تبدیل کنید و `BOT_TOKEN` را وارد کنید.
3. در همان پوشه اجرا کنید:

   ```sh
   docker compose up --build -d
   ```

4. در تلگرام `/start` را بفرستید. برای دیدن شناسهٔ خود `/id` را بفرستید و آن را در `ALLOWED_USER_IDS` قرار دهید.

## استقرار با Render یا Railway

- ریپو را در GitHub نگه دارید و آن را به Render یا Railway وصل کنید.
- سرویس Dockerfile را انتخاب کنید.
- دست‌کم `BOT_TOKEN` را به‌عنوان secret/environment variable تنظیم کنید.
- در صورت نیاز دسترسی را با `ALLOWED_USER_IDS` محدود کنید. چند شناسه را با کاما جدا کنید.
- پورت سرویس از `PORT` خوانده می‌شود؛ سرویس‌های ابری معمولاً آن را خودکار تنظیم می‌کنند.

فایل‌های `render.yaml` و `railway.json` تنظیمات پایهٔ استقرار را آماده می‌کنند. برای اینکه URL عمومی سایت هم داشته باشید، یک Web Service با polling بات و health check روی `/` اجرا کنید.

## تنظیمات

| متغیر | پیش‌فرض | کاربرد |
|---|---:|---|
| `BOT_TOKEN` | الزامی | توکن BotFather |
| `ALLOWED_USER_IDS` | خالی | شناسه‌های عددی مجاز با کاما؛ خالی یعنی هر کاربری می‌تواند بات را استفاده کند |
| `MAX_UPLOAD_MB` | `49` | سقف فایل خروجی؛ حداکثر 49 مگابایت برای سازگاری با Bot API |
| `MAX_PLAYLIST_ITEMS` | `500` | سقف آیتم‌های پلی‌لیست yt-dlp و قطعه‌های Spotify (حداکثر ۵۰۰۰) |
| `MAX_DURATION_SECONDS` | `7200` | سقف مدت رسانه، پیش‌فرض دو ساعت |
| `MAX_CONCURRENT_DOWNLOADS` | `2` | سقف کارهای هم‌زمان، بین 1 تا 8 |
| `SPOTIFY_AUDIO_FORMAT` | `mp3` | یکی از `mp3`, `flac`, `ogg`, `opus`, `m4a`, `wav` |
| `SPOTIFY_BITRATE` | `192k` | نرخ بیت خروجی spotDL |
| `COOKIES_FILE` | خالی | مسیر فایل کوکی برای رسانه‌های مجازِ نیازمند ورود |
| `PORT` | `8000` | پورت health check |

`MAX_PLAYLIST_ITEMS` سقف تعداد آیتم برای پلی‌لیست‌های yt-dlp و لینک‌های Spotify است؛ پیش‌فرض ۵۰۰ و بیشینهٔ قابل تنظیم ۵۰۰۰ آیتم است. فایل هر آیتم جداگانه فرستاده می‌شود و اگر از سقف `MAX_UPLOAD_MB` بزرگ‌تر باشد رد می‌شود.

## نام و پروفایل تلگرام

تصویر آمادهٔ پروفایل در [`assets/bot-avatar.png`](assets/bot-avatar.png) است و متن پیشنهادی نام، توضیح و فرمان‌ها در [`BRANDING.md`](BRANDING.md) قرار دارد. نام و تصویر را یک‌بار در BotFather روی بات خود اعمال کنید؛ این مرحله به حساب تلگرام و توکن خودتان نیاز دارد.

## اجرای محلی بدون Docker

Python 3.12 و FFmpeg نصب کنید، وابستگی‌ها را نصب کنید و `.env` را بسازید:

```sh
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python bot.py
```

## حریم خصوصی و محدودیت‌ها

- لینک‌ها و رسانه برای پردازش به سایت مبدأ فرستاده می‌شوند؛ فایل‌ها پس از ارسال پاک می‌شوند.
- برای استفادهٔ خصوصی، `ALLOWED_USER_IDS` را تنظیم کنید. اگر خالی بماند، بات عمومی است.
- لینک‌های شبکهٔ خصوصی و `localhost` رد می‌شوند.
- بات محتوای DRM یا محتوای خصوصی را دور نمی‌زند. کوکی فقط برای حساب/محتوایی به‌کار رود که اجازهٔ دسترسی به آن را دارید.
- سقف ارسال فایل از محدودیت Bot API پیروی می‌کند و بسته به تغییرات تلگرام ممکن است عوض شود.

## توسعه

کد اصلی در `bot.py` است. گزارش مشکلات extractorهای سایت‌ها را در [yt-dlp](https://github.com/yt-dlp/yt-dlp/issues) و خطاهای تطبیق آهنگ را در [spotDL](https://github.com/spotDL/spotify-downloader/issues) ثبت کنید.

برای اجرای تست‌های آفلاین: `python -m unittest discover -s tests -v`. تست زندهٔ دانلود MP4 عمومی و پلی‌لیست دوآیتمی PeerTube را با `RUN_LIVE_MEDIA_TESTS=1 python -m unittest tests.test_live_media -v` اجرا کنید.
