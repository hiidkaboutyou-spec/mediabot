# Telegram profile: دانلودچی

Use this profile for the bot created with BotFather. The username must be chosen separately in Telegram and must be available.

- **Display name:** دانلودچی | Media Bot
- **Profile image:** [`assets/bot-avatar.png`](assets/bot-avatar.png)
- **Short description (About):** دانلودچی؛ دریافت و ارسال ویدیو، صدا و پلی‌لیست از لینک‌های عمومی پشتیبانی‌شده.
- **Long description:** لینک رسانه یا پلی‌لیست عمومی را بفرست، کیفیت را انتخاب کن و فایل‌ها را در تلگرام بگیر. دریافت فقط برای محتوایی که اجازهٔ دانلودش را داری.
- **Commands:**

  ```text
  start - شروع کار با دانلودچی
  help - راهنمای استفاده و محدودیت‌ها
  id - نمایش شناسهٔ تلگرام
  ```

## Apply in BotFather

1. Open `@BotFather`, choose `/mybots`, and select your bot.
2. Set the display name and descriptions using **Edit Name**, **Edit About**, and **Edit Description**.
3. Choose **Edit Botpic** and upload `assets/bot-avatar.png`.
4. Set the commands using `/setcommands` and paste the list above.

The repository cannot change a Telegram profile without the owner's BotFather session. The generated icon and copy are ready to apply.
